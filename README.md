FEATURES

The website includes the following features:

- Home page with an introduction to St. Mary's College Kisubi.
- About page providing information about the school.
- Academics page presenting academic information.
- Gallery page displaying school-related images.
- Contact page providing contact information.
- Navigation menu for moving between the different pages.
- Responsive layout for different screen sizes.
- Interactive elements implemented using JavaScript.


WEBSITE PAGES

Home
The Home page provides an introduction to St. Mary's College Kisubi and gives visitors an overview of the website.

About
The About page provides information about the school and its background.

Academics
The Academics page provides information about the school's academic activities and programs.

Gallery
The Gallery page displays images related to the school and its activities.

Contact
The Contact page provides information that visitors can use to get in touch with the school.

HOW TO RUN THE PROJECT LOCALLY
1. Clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the `home.html` file in a web browser.
4. Alternatively, install the Live Server extension in Visual Studio Code.
5. Right-click `home.html` and select "Open with Live Server".
